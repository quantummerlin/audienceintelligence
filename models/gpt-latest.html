What is ~openai/gpt-latest?

The tilde prefix (~) signals an auto-updating routing alias on OpenRouter. Unlike pinning a specific model version like openai/gpt-5-5, the ~openai/gpt-latest alias automatically routes your requests to OpenAI's current flagship GPT model the moment it's available.

This is the broadest OpenAI alias—it tracks the latest general-purpose GPT flagship, which may include reasoning variants and capability expansions. It differs fundamentally from openai/gpt-chat-latest, which is narrowly optimized for chat interactions.

When OpenAI releases GPT-5.6, GPT-6, or future versions, requests to ~openai/gpt-latest will automatically route there. No code changes needed.

Using ~openai/gpt-latest via OpenRouter

Access the alias through OpenRouter's standard API. Here's a Python example:

import openai client = openai.OpenAI( base_url="https://openrouter.io/api/v1", api_key="your-openrouter-key" ) # Request with the auto-updating alias response = client.chat.completions.create( model="~openai/gpt-latest", messages=[ {"role": "user", "content": "Explain quantum entanglement"} ] ) print(f"Resolved model: {response.model}") # Output: "Resolved model: gpt-5-5"

The response.model field tells you which version the alias resolved to, enabling you to log and monitor routing behavior across your infrastructure.

What Is the Tilde Prefix?

The ~ prefix denotes an auto-updating OpenRouter routing alias. When you call ~anthropic/claude-haiku-latest, OpenRouter transparently resolves it to Anthropic's current recommended fast model, without any code changes on your end.

The routing flow looks like this: 

~anthropic/claude-haiku-latest
  ↓ (today)
Claude Haiku 4.5 (today)
  ↓ (on upgrade)
Claude Haiku 4.6 (next)
  ↓ (eventually)
Claude Haiku 5.0 (future)

For a deeper technical breakdown of how tilde aliases work in OpenRouter, see the ~anthropic/claude-sonnet-latest guide.

Haiku Track Upgrade Pattern

Haiku upgrades have historically focused on speed and efficiency, not capability leaps. Unlike Opus (which brings major reasoning breakthroughs) or Sonnet (balanced capability + speed), Haiku upgrades target throughput, latency, and cost-per-token stability.

When Haiku 4.6 ships, expect:

  • Modest latency improvements (5–15% faster inference)
  • Incremental capability gains (better at nuanced classification, extraction edge cases)
  • Possible pricing adjustments (usually small, $1.50/$6 range)
  • Same context window and vision support

The Haiku track is stable — the model you're using today won't break tomorrow, but it will silently become faster as the alias updates.

Alias vs. Pinned Versions: When to Use Each

The choice between ~anthropic/claude-haiku-latest (alias) and anthropic/claude-haiku-4-5 (pinned) depends on your deployment model and cost visibility.

Use the Alias When

  • You're in early prototyping phase and want latest speed
  • Running high-volume production with auto-scaling capacity
  • Cost-per-token is stable across versions
  • You monitor usage metrics actively
  • Building internal tooling (moderation, triage, classification)

Pin a Version When

  • Cost budget is locked for a quarter or year
  • Behavior has been tested and validated against Haiku 4.5
  • Production SLA requires predictable model behavior
  • You want to control upgrade timing manually
  • Regulatory or compliance rules require version pinning

Code Example: Using Claude Haiku Latest

Here's how to call ~anthropic/claude-haiku-latest via the Anthropic SDK (which uses OpenRouter by default for routed aliases): 

import anthropic

client = anthropic.Anthropic(
    api_key="your-openrouter-api-key",  # or Anthropic API key for direct calls
    base_url="https://openrouter.io/api/v1"  # OpenRouter routing
)

message = client.messages.create(
    model="~anthropic/claude-haiku-latest",
    max_tokens=1024,
    messages=[
        {"role": "user", "content": "Classify this customer support ticket..."}
    ]
)

print(f"Model used: {message.model}")
print(f"Usage: {message.usage}")

The response will include the actual resolved model ID (e.g., claude-haiku-4-5-20250516), so you can track which version is currently being used.

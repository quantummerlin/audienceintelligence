🎯 Prompt Techniques (from dataset)
Grid / Multi-image Prompts
Generate a 3×3 grid of [subject]. Each panel shows a different [camera angle/scene/step]. Maintain consistent [character/product] throughout. Number the panels 1-9 and show evolving narrative.
Character Consistency Prompt
[Use uploaded reference image]. Cinematic editorial photo. Character should maintain exact appearance including [specific details like hair, tattoos, clothing]. AR 4:5. Photorealistic.
Product Commercial Prompt
High-end commercial marketing campaign for [product]. 3×3 grid. Nine frames showing different use contexts: morning routine, outdoor lifestyle, gifting, close-up detail, before/after, hero shot with tagline "[tagline]". Use brand colors #[hex1] and #[hex2]. Font: [FontName] for all text.
Infographic Prompt
Professional infographic titled "[Title]". Include [5-7 key stats/facts]. Clean layout with brand colors #[hex1], #[hex2]. Use [Font] for headings. All text must be perfectly rendered and factually accurate. AR 9:16 tall format. Print-ready quality.
Web Browse + Create
Browse the internet for the latest [topic/event/stats]. Use exact, current data. Create a highlight card / social post with this information. Include source attribution in small text. Use [brand colors]. AR 1:1.

💡 Pro Tips from Dataset
Use full font name + hex colors: Instead of "blue text", write "Use Pacifico font for the headline. Text color: #1A73E8". GPT Image 2 will browse and apply the exact font.
Thinking mode = quality: Adding "thinking mode" or using the API with higher reasoning effort gives significantly better outputs — worth the extra cost for hero images.
Grid then extract: Prompt it to "generate a 3×3 grid" then follow up: "extract, enhance and upscale all 9 frames individually". Gets you 9 hero images efficiently.
Specify AR with "AR" prefix: Write "AR 9:16" or "AR 3:2" in your prompt. Supports any ratio. Default tends toward square if unspecified.
Production sheets beat single prompts: Create a storyboard/production sheet image first (showing scenes, notes, angles), then feed it to the model to generate all assets — like a professional pre-production workflow.
For realism — prompt for imperfections: "Add subtle natural imperfections, slight grain, real-world lighting inconsistencies" makes images feel photographed not generated.
API model names on OpenRouter: Use openai/gpt-5.4-image-2 for image generation. For reasoning/text use qwen/qwen3.5-plus-20260420 or openai/gpt-5.4.

# AI Website Builder

> From blank page to launch-ready blueprint in one session. Let AI handle the decisions that slow you down.

## When To Use This

- You need to build or redesign a website quickly with strong messaging
- You are iterating landing pages, offer pages, or microsites
- You want AI to make the structural and copywriting decisions — not just assist
- You are building for a client and need a complete brief fast

## Workflow

1. **Clarify audience, offer, and conversion event before any layout decisions.** Who lands here? What do you want them to do? What objection will stop them? These three answers unlock every design and copy choice.
2. **Generate structure and content blocks tied to user intent.** Let AI propose the section hierarchy — hero, problem, solution, proof, CTA — then refine each block individually.
3. **Apply visual rhythm, typography contrast, and proof architecture.** Spacing, headline scale, and social proof placement convert visitors. Get these right before polishing details.
4. **Run quality checks for mobile, speed, and message clarity.** Does it work on a phone? Does it load fast? Can you understand the offer in 5 seconds? Ship when all three pass.

## Signal Prompt

```
I am building a website for: [describe your offer, service, or product].

Target audience: [who they are, what they already know]
Conversion goal: [what action you want them to take]
Main objection: [the biggest reason they'd leave without converting]

Build me:
1. A section-by-section page structure (hero → proof → CTA flow)
2. Headline and subheadline copy for each section
3. Visual direction notes (layout, typography emphasis, proof types)
4. 3 headline variations for A/B testing

Keep everything specific to my offer — no generic filler.
```

## Expected Output

A complete website blueprint with section structure, copy, visual direction, and A/B test variants — ready to implement in any tool.

# Video Prompt Builder

> Stop guessing at video prompts. Build a framework that produces consistent, high-quality results every time.

## When To Use This

- You are generating AI video with tools like Veo 3, Sora, Kling, or Runway
- Your outputs are inconsistent and you need a repeatable prompt structure
- You want to produce multiple variations for testing without starting from scratch
- You are running video campaigns and need a scalable prompt system

## Workflow

1. **Define the objective, audience, and conversion action.** What does this video need to do? Who is it for? What should the viewer do next? These answers shape every prompt decision.
2. **Specify scene logic, framing, and narrative constraints.** Where does the video start and end? What transitions matter? What must appear on screen and when?
3. **Add explicit style, pacing, and editing directives.** Cinematic vs. raw, fast cuts vs. slow reveals, color grade, camera movement — be specific. Vague style = generic output.
4. **Iterate with versioned variants and scoring.** Keep a record of what worked. Score outputs on clarity, style adherence, and conversion potential. Improve from evidence.

## Signal Prompt

```
Build a video prompt framework for: [describe your video concept or campaign].

For each prompt, include:
- Scene 1: [opening — what the viewer sees first, camera angle, lighting mood]
- Scene 2: [development — main message, visual proof, key moment]
- Scene 3: [close — CTA or emotional payoff]
- Style: [cinematic / documentary / UGC / product-forward]
- Pacing: [fast cuts / slow reveal / single continuous shot]
- Constraints: [no text overlays / no faces / outdoor only / etc.]

Generate 3 variations with different emotional angles. Score each on: hook strength, message clarity, and production difficulty.
```

## Expected Output

A structured video prompt framework with 3 scored variations — ready to run in your AI video tool of choice.

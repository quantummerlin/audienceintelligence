💡 Cost-Saving Tips

🎯 Use the Right Model for the Task

Most agent tasks don't need Opus or GPT-4. Use Sonnet or GPT-4o Mini for routine operations. Switch to premium models only for complex reasoning tasks.

📊 Enable Memory Compression

OpenClaw's default memory sends full conversation history. Enable compression to reduce token usage by 50-70%.

🛑 Set Budget Caps

Add a daily spend limit in your config to prevent runaway agents. A $10 cap could save you from a $200 surprise bill.

🔄 Implement Caching

Enable response caching for repeated queries. This can save 10-30% on tokens for common operations.

?? The Surveillance Infrastructure CRITICAL FINDING

THE MECHANISM

Persistent Age Broadcasting, Not Point Verification

The legislation doesn't create age verification at the moment someone tries to access adult content. Instead, it mandates that operating systems implement a continuous service where any installed app can query a system-level API that returns your age bracket in real time.

"Every app on your device gets to query a system-level API that returns your age bracket in real time. This isn't age verification at the point of accessing restricted content. This is a persistent age-broadcasting service baked into the operating system itself, queryable by every installed application."
THE VEHICLE

ICMEC Template Bills Spreading State-to-State

The legislation uses template bills from the International Centre for Missing & Exploited Children (ICMEC) that have spread to 45 states. The same language appears verbatim in bills across the country, making it nearly impossible for local advocates to fight each one individually.

"The template bill defines 'operating system provider' so broadly that it captures FOSS projects, small developers, and anyone who maintains code that could be considered an operating system."
THE SCOPE

No Data Minimization Requirements

Unlike the EU's GDPR-based approach, which emphasizes data minimization and user consent, the US bills have no such provisions. Once your age is in the system, it's queryable by any app — gaming, shopping, social media, dating — without your knowledge or consent each time.

"DCA is not there. No EIN exists for this organization."
